# 牌面类别枚举（v0.1 · 地基）

> 所有笔记打标都用这一套。改这张表 = 全库返工，所以先冻结再扩。

## 三个维度

| 维度 | 取值 |
| :--- | :--- |
| 高度 | 高（A/K 顶张）、中（Q–T）、低（9 以下）、轮子（A-3-2 / A-5-4） |
| 连接 | 连（顺子密集）、半连、断 |
| 花色 | 彩（彩虹）、两色、天花（三张同花）、公对 |

## 转牌：不枚举牌面，只标变化类型（8 种）

空白 / 高张 / 成花 / 成顺 / 成对 / 完成两头 / 完成卡顺 / 双高

理由：转牌有 47 种，乘上去永远填不完；而策略只对「牌面性质变了没」敏感。
